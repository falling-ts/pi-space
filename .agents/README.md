# .agents/ — agent 运行期工作区

本目录存放 **agent 自己的运行期产物**，与 `docs/`（正式文档）、`refs/`（外部参考源码）区分开。

## 约定

| 子目录 | 用途 | 入库 |
| --- | --- | --- |
| `tmp/` | 一次性中间产物、下载缓存 | ❌ 已忽略 |
| `scratch/` | 试验性代码（例如改 `refs/pi` 的副本） | ❌ 已忽略 |
| `cache/` | 可重建的索引/解析结果 | ❌ 已忽略 |
| `sessions/` | 会话记录、任务日志 | ❌ 已忽略 |
| `notes/` | 值得长期保留的 agent 笔记 | ✅ 建议入库 |

- 需要长期留存的内容请整理进 `docs/`，不要留在被忽略的目录里。
- 试验上游代码时，把 `refs/pi` 的副本放到 `scratch/`，不要直接改子模块工作区。
- 忽略规则见仓库根 [`../.gitignore`](../.gitignore)。
